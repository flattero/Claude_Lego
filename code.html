How it works

      
Drag blocks under when ▶ Run is clicked, connect the brick, then press Run.
        The block that is running lights up. Press Stop at any time. Blocks not attached under a Run block don't run.

      
Ports: motors are A, B, C; sensors are 1–4. On the standard 9797 robot, the wheels are B and C.
